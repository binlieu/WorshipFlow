- LIB-005: program export and import. File > Export Program… (and the playlist menu) writes one playlist, its presentations (slides, sections, languages, notes, objects, slide actions, arrangements), headers, countdowns, scripture items (reference and codes only), the themes and Looks they use, the media bin items their actions play, and a copy of every media file as `<name>.worshipflowprogram`, a folder package declared as `org.worshipflow.program` that Finder treats as one file; `program.json` holds only paths relative to the package. File > Import Program…, opening one from Finder or dropping it on the window shows a summary (new, already there, in conflict, media to copy, missing media) and asks once how to treat conflicts (keep both by default, keep mine, use the imported one); the import is one database transaction and removes the media it copied if anything fails. Imported media lives in `Media/Imported/<program id>/` beside the library and is stored as a path relative to the library's folder (`Persistence/ProgramDoor.swift`), so it survives moving the library folder. A package is untrusted: absolute or escaping paths, links, an oversized or newer-format `program.json` and damaged files are refused before anything is written. New package target `ProgramPackage` (+ `ProgramPackageTests`), `App/Info.plist` generated from `project.yml`. No migration. See `docs/features/LIB-005-program-export-import.md` and `AI/reports/LIB-005-report.md`.
