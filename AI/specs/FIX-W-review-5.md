## Fixes, each test-first (write the test, see it fail for the stated reason, then fix; one commit-sized change per item)

1. **M1: a marker crossed just before a pause, Stop or the clip's end never runs.** Before the feed is stopped or reset, the crossings between the last tick and the final position must be delivered once. The rule "once per crossing" must hold: not twice on a loop, a seek across the marker, pause then resume (review L5: within about 8 ms of a marker it can run twice: fix it in the same change if the cause is the same state, otherwise leave it and say so), or with two outputs. Marker actions keep going through the command path. Nothing ticks while idle. Tests with an injected clock and positions; no wall-clock assertions.
2. **M2: removing a mirror leaves `connectedToKey` and `signalChains` on the wrong destination.** `ScreenEditing.removingMirror` must keep every per-destination array aligned (find every such array on `ScreenProfile`; do not assume there are only three). Check the other editing functions that add, remove or reorder destinations for the same fault. The related point (a key note kept but hidden when a destination goes from Fill and Key to plain) is acceptable as it is: leave it and note it.
3. **M3: on package import a marker's Look action is not remapped through `lookMap`.** A marker action that selects a Look imported under a new id must select the imported Look, the same way slide actions are remapped (`ProgramImportPlan.swift:248`). Check every other id kind a marker action can carry (assets, macros, anything else slide actions remap) and remap them the same way.
4. **M4: a video object that fails to open, or is beyond the player limit, draws nothing on air and the operator is not told.** The app must read the object players' `unavailableAssetIDs` and `skippedAssetIDs` and show it where the operator already sees media problems (the path `AppModel.swift:1155` uses for `mediaRegistry.unavailableAssetIDs`), with plain text naming the clip and the reason (could not be opened; more video objects on one slide than can play at once, with the limit). Clear the flag when the clip later opens (review L1). Keep it off the render thread; no new timer while idle. Do not change the player limit or what is drawn.
5. **M5: Edit's Broadcast and Stage previews ignore the screen's own Look,** and (review L12, the partly fixed REVIEW-4 M1) Edit's Stage preview has no section names so Section and Next section draw nothing. `EditPreviewScene` must build its scene with the same per-screen Look overrides and section names the live path passes, so the preview is what that screen would show. Editing must still never change Live. The existing test for the Stage preview uses a deck with no section names: add a test with real section names; do not edit the existing one.
6. **L6: the v15 backup is skipped silently when the library history cannot be read.** A migration must not run without the copy unless the library is new and empty. If the backup cannot be made, refuse to migrate and report an actionable error, leaving the library untouched. Read ADR-0009 and keep to it; if this conflicts with the ADR, stop this item and report. Tests on temporary libraries only.
