# FIX-N: fixes from the independent review of FIX-K and the Stage canvas editing

Feature IDs: FIX-K, UI-005e. Model: Sonnet. One agent in the main folder, after FIX-M is committed. No migration.

The review of commits 0f60914 and 6f95c1d (2026-11-22) found one high and several medium defects. Test-first, order checked, failing output recorded per item. New tests in `FIXN_*.swift`. Do not edit existing tests. Items 1 and 3 must also be exercised in the running app with real key events through the debug hook, in each of Edit, Stage and Screens, after a click on a canvas box, after a drag, and after a sheet closes: this class of defect has shipped three times behind passing unit tests.

## Items

1. **Fix (high): after a click on a Stage canvas box, Space, Return and B do nothing.** The canvas's key-catching view reports itself to the router as a slider, and a slider passes every key but Escape through to the control, so the show's keys are swallowed until Escape is pressed. Decision: a canvas (Stage and Edit) takes **only the arrow keys** (with and without Shift), and only while a box is selected; every other key is routed exactly as if the slide grid had focus, so Next, Previous, Go Live, Blackout, Clear, Clear all and Stop always work in every mode. Model the canvas as its own focus kind in the routing function rather than borrowing "slider". Check the Edit canvas for the same defect and say what you found. After a drag ends, a sheet closes or the mode changes, the show's keys work without an extra Escape.
2. **Fix (medium): stored text frames are not validated when read.** Decoding a slide's own text frame (from the database, from a program package, from the scene) goes through the same clamp the editor uses; a frame with zero or negative size, non-finite values, or wholly outside the canvas is treated as no override. Hostile-JSON tests through each decode path, including program import, and a render test that a bad frame draws the theme's position.
3. **Fix (medium): in Edit, Stage and Screens nothing shows that the screens are blacked out or cleared.** The owner asked for the red LIVE chip to go because it was busy, and it stays gone. But an operator who presses B there gets no feedback. Decision: a small, quiet, non-red state tag in the toolbar that is **only present while** the show is blacked out ("BLACKOUT") or cleared ("CLEARED"), in every mode; absent otherwise, so the toolbar is as calm as the owner asked when nothing unusual is on. Record in the change log that this adds back less than was removed, and why.
4. **Fix (medium): the background clear icon ignores a theme's own background.** A theme whose background is a video or picture is something Clear background removes, so the icon is enabled and shows its kind. Tooltip names it ("Clear background: theme video").
5. **Fix (medium): holding an arrow key on the Stage canvas writes, publishes and records an undo step about 30 times a second.** Nudges move the transient frame and are committed once when the key is released or after a short quiet period (injected clock), as one undo step per run of nudges; same for Edit if it differs. A stage screen updates once per commit.
6. **Fix (medium to low): an interrupted drag leaves the Edit interaction open,** after which a position typed in the inspector for a lyric box shows but is never saved. End the interaction on mouse-up, on cancel, when the slide, presentation or mode changes, when the window resigns key, and when the view disappears; the inspector's fields always write. Same check for the Stage canvas (a stuck pressed state).
7. **Fix (medium to low): "Apply to all slides in this song".** It skips slides where that language has no words, asks once before applying ("Apply this position to N slides?"), and is one undo step that restores every slide.
8. **Fix (low):** the nudge undo grouping ends when the selection changes, another edit happens, or the quiet period passes; `lyricBoxes` does not recompose the scene on every access (cache per content and theme revision) and does not depend on exact text equality to find its layer; the commit counter and any other test-only observer is compiled out of release builds; arrows nudge the selected box whenever the canvas was the last thing clicked, even if a toolbar button has focus since.
9. **Add the tests the review found missing:** a copied slide's content carries its frames; key routing for the canvases in every mode; Stage pointer behaviour for a cancelled drag; replace the source-text check `FIXK_CanvasGestureSourceTests` with behaviour tests where possible (add new tests; leave the old file as it is).
