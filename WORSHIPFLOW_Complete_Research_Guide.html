01

Executive overview

WORSHIPFLOW is presented here as a production system for displaying worship lyrics, Bible passages, slides, videos, announcements, confidence monitors, and livestream graphics with independent output control.

What the system should do

Reuse one content source across multiple destinations, while allowing each screen to have its own formatting, overlays, and operational role.

One song, three different looks: full-screen lyrics for the sanctuary, lower-thirds for broadcast, and next-line guidance for musicians.

Critical hardware distinction

The DeckLink Duo 2 has four configurable SDI BNC connections, not HDMI ports. Thunderbolt connects the PCIe enclosure to the computer. Convert SDI to HDMI only at destinations that require HDMI.

Format ceiling: the Duo 2 is a 3G-SDI HD card, not a 4K video output card.
02

How WORSHIPFLOW communicates with hardware

Different transports perform distinct jobs: frame rendering, broadcast video, network video, and command/control should be designed and troubleshot independently.

Thunderbolt carries PCIe data to the enclosure, not four native HDMI signals. DeckLink creates the four SDI signals; an HDMI-only destination needs an active SDI-to-HDMI converter.

11

Thunderbolt + DeckLink installation procedure

Use these steps to establish the video hardware path before designing screen content and automation.

Install the DeckLink card

Power down the PCIe enclosure. Insert the DeckLink Duo 2 in a suitably sized PCIe slot, secure its bracket, power the enclosure, and use a genuine Thunderbolt cable to connect it to the Mac.

Install Desktop Video

Download a version supported by your macOS release and the card. Approve any required driver extensions or permissions and restart if requested.

Verify hardware detection

Open Desktop Video Setup and check that the DeckLink appears. Inspect firmware and connector configuration before opening WORSHIPFLOW.

Choose the port roles

Set the four SDI connectors as independent outputs, or reserve two connectors as Fill and Key for alpha-key graphics. The latter consumes two physical channels.

Configure WORSHIPFLOW screens

In the proposed screen configuration interface, create Audience and Stage screens and assign each to the correct detected SDI playback device.

Match video formats

Use a common production format, such as 1920 × 1080 at 59.94 fps, if the receiving switcher/displays support it. 59.94 and 60 fps are distinct modes.

Connect to HDMI destinations

For every HDMI-only input, connect SDI BNC → powered SDI-to-HDMI 3G converter → HDMI cable → destination. Do not substitute a passive BNC-to-HDMI cable.

Create looks and layouts

Prepare separate audience graphics, lower thirds, and stage confidence layouts. Keep source content reusable across the different compositions.

Test before a service

Show calibration slides, verify all port mappings, check key polarity and video timing, validate audio routing, and monitor frame drops under load.

Diagnostic sequence: first verify the card in Desktop Video Setup, then test the SDI output in a Blackmagic utility such as Media Express, and only then troubleshoot the WORSHIPFLOW screen mapping.

ATEM wiring: convert each of the two SDI signals into separate HDMI connections, assign one as Fill and one as Key in the keyer, and configure straight/premultiplied alpha appropriately. This uses two ATEM HDMI inputs.

What about direct HDMI from the Mac?

A native Mac HDMI or supported USB-C display output can feed an ATEM input directly. It is simpler and lower-cost for one channel. A dedicated DeckLink path becomes attractive when several independent production outputs are needed or when you require professional SDI transport.

13

Mac, ATEM & audio integration

Mac mini considerations

A Mac mini M4 supports a limited number of native desktop displays; an external DeckLink device is an SDI video peripheral rather than four additional desktop monitors. All compositions still consume processing and graphics resources.

Validate simultaneous output count, heavy media playback, and any Key + Fill compositing on the exact Mac and enclosure under production conditions.

ATEM responsibilities

Use WORSHIPFLOW for slides, lyrics, confidence displays, and live graphics. Use the ATEM for multi-camera switching, broadcast keying, and the final program feed. Set all devices to a common video format where supported.

An ATEM HDMI input typically needs a direct HDMI feed or an active SDI-to-HDMI converter.

Audio routing strategy

For a production using an Allen & Heath QU-32, keep microphones and instruments on the mixer. Send the desired livestream mix to the ATEM once. Route playback audio from WORSHIPFLOW deliberately through a designated audio path and avoid duplicating the same signal through both the mixer and an SDI/HDMI source.

ApproachAdvantagesTradeoffs
Native Mac HDMI → ATEMSimple; no external PCIe card neededUses a macOS display output
DeckLink SDI → converter → ATEMDedicated SDI transport, multiple outputsRequires PCIe enclosure, SDI cabling and converters
DeckLink paired Fill + Key → ATEMIndependent broadcast graphics transparencyConsumes 2 SDI ports and 2 HDMI inputs
Frame-rate rule: standardize on 1920 × 1080 at 59.94 fps if every endpoint supports it; do not casually mix 59.94 and 60.
